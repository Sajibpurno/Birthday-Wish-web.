# 🎂 Birthday Wish Website

তোমার girlfriend এর জন্য একটি beautiful animated birthday wish website!

## 📁 Setup Instructions (কিভাবে use করবে)

### Step 1: Images Add করো
`images/` folder এ তোমার girlfriend এর photos রাখো:
- `photo1.jpg` - First memory photo
- `photo2.jpg` - Second memory photo
- `photo3.jpg` - Third memory photo
- `photo4.jpg` - Fourth memory photo
- `photo5.jpg` - Fifth memory photo
- `photo6.jpg` - Sixth memory photo

আরও বেশি photos চাইলে HTML file এ gallery section এ add করতে পারো।

### Step 2: Messages Customize করো
`index.html` file open করো এবং edit করো:

1. **Letter Section** - "A Letter For You" এ তোমার নিজের message লেখো
2. **Love Notes** - "Why I Love You" cards এ তোমার notes লেখো
3. **Gallery Captions** - প্রতিটা photo এর নিচে caption change করো
4. **Her Name** - "My Love" জায়গায় তার নাম দিতে পারো

### Step 3: Background Music (Optional)
`music/` folder এ একটি romantic song রাখো:
- File name: `birthday-song.mp3`

### Step 4: Website Open করো
`index.html` file টা browser এ drag & drop করো অথবা double click করো!

## 🎨 Customization Tips

### Colors Change করতে চাইলে
`styles.css` file এ এই colors পাবে:
- Main pink: `#ff6b6b`
- Gold/Yellow: `#ffd93d`
- Background: `#1a1a2e`

### More Photos Add করতে
`index.html` এ gallery section এ এই code copy করে paste করো:
```html
<div class="gallery-item">
    <img src="images/newphoto.jpg" alt="Memory">
    <div class="overlay">
        <p>Your caption here ❤️</p>
    </div>
</div>
```

### More Love Notes Add করতে
```html
<div class="note-card">
    <div class="note-icon">💝</div>
    <h3>Your Title</h3>
    <p>Your message here...</p>
</div>
```
